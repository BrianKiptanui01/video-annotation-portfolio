#Video Annotation Portfolio

Project Overview

This project demonstrates practical skills in video annotation and data labelling for Artificial Intelligence (AI) training.

The purpose is to identify objects, recognise activities, describe events and assign accurate timestamps to video content.

Project Objectives

- Identify objects appearing in video footage.
- Describe human activities and movements.
- Record accurate start and end timestamps.
- Organise annotations into structured datasets.
- Review annotation quality and consistency.

Skills Demonstrated

- Video content analysis
- Object identification
- Action recognition
- Timestamp annotation
- Data labelling
- Attention to detail
- Quality assurance

Project Files

- "annotations.csv" - Sample video annotation dataset.
- "guidelines.md" - Video annotation guidelines.
- "quality_review.md" - Annotation quality review.

Project Status

Beginner-level practical portfolio project. The current dataset contains illustrative sample annotations for demonstration purposes.

Author

Created as a practical project to demonstrate video annotation and AI data quality skills.
